# Security policy

Do not open public issues containing API keys, cloud credentials, customer domains, database contents, logs with personal information, or backup files.

The hosted service must keep provisioning in dry-run mode until authentication, payment verification, persistent storage, idempotency, encrypted secrets, per-tenant network and volume isolation, backup restoration, and signed application images are verified end to end.

Self-hosters are responsible for cloud IAM, billing limits, DNS ownership, backups, and operating-system security updates.
